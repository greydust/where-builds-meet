# Scripts

Active scripts are grouped by purpose:

- `deploy/` retains previous deployment assets.
- `i18n/` extracts and verifies translation catalogs.
- `logo/` builds and previews application icons.
- `probe/` contains benchmarks, not checks or release gates.

`archive/` contains one-off datamining and migration scripts retained for historical reference. They target former data paths and are not runnable against the current tree.
