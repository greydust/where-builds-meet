# Path buffs and skill damage boost categories

> **Historical snapshot (2026-10-21).** This is evidence from an earlier working tree, not a current source of truth. See the [documentation index](README.md) for current references.

Snapshot: 2026-10-21, current working tree, including uncommitted changes.

This is an inventory of simulator assignments for datamining verification, not a claim that the categories are confirmed in game. Every entry is **pending datamine confirmation**. No calculation or game data is changed.

## Scope and reading guide

Includes all current non-preview path buff/debuff files, shared buff/debuff files, direct skill modifiers, martial-art talents, Inner Way definitions, and DOT definitions. Shared and Inner Way sources are included because they can supply path or skill bonuses. Planner-only paths are included where data exists; Jade has no dedicated buff/debuff file. Alternate records under `data/preview/`, equipment, food, Script, Divinecraft setup bonuses, and attunement are outside this inventory.

Rows identify each authored bonus occurrence by source file and JSON pointer (zero-based array indices). Talent indices are authored rank indices; stackEffects indices are zero-based stack tiers, not additive layers. Repeated rank or stack entries are intentionally retained. Values remain decimal ratios: `0.1` means 10%. Formula objects remain verbatim. Requirements and activation metadata are inherited from enclosing records; consult the pointer for full trigger/action sequencing and refer to related Inner Way records for upgrades. Buff duration, application stacks, eligibility, and source skill selection still govern when an effect exists.

Attack scaling and flat/coefficient scaling are included as adjacent categories so they cannot be mistaken for final damage bonuses. Raw attack stats, penetration, defense reduction, rate bonuses, healing, and ordinary skill damage coefficients/flat damage are not percentage damage boosts and are not enumerated. A record with no matching bonus field may still increase DPS through extra hits, timing, or other mechanics.

## Category key

Assignments follow [damage-formula.md](damage-formula.md), [skill-data.md](skill-data.md), and [damage.ts](../src/calculations/damage.ts). These describe implementation behavior; datamining must verify the game-side category separately.

| Field                               | Current simulator category                        |
| ----------------------------------- | ------------------------------------------------- |
| `dmgBonus`                          | Category 1 (additive)                             |
| `hpDMGBonus`                        | Category 1 (additive)                             |
| `baseDMGBonus`                      | Base damage multiplier                            |
| `globalDmgBonus`                    | Mechanism multiplier                              |
| `globalHPDMGBonus`                  | Mechanism multiplier                              |
| `globalBellstrikeDMGBonus`          | Mechanism multiplier (Bellstrike only)            |
| `attributeDMGBonus`                 | Category 1 (attribute components only)            |
| `dotDamage`                         | DOT multiplier                                    |
| `highBleedDamage`                   | DOT multiplier (HighBleed only)                   |
| `critDmgBonus`                      | Critical outcome multiplier                       |
| `affinityDmgBonus`                  | Affinity outcome multiplier                       |
| `flatAttackBonus`                   | Flat attack term scaling                          |
| `coefficientBonusWithoutFlatAttack` | Coefficient scaling when both flat terms are zero |
| `replayDmgBonus`                    | Replay-only multiplier                            |
| `qiDMGBonus`                        | Qi damage (not currently evaluated)               |
| `physDmgBonus`                      | Physical channel multiplier                       |
| `bellstrikeDmgBonus`                | Bellstrike channel multiplier                     |
| `stonesplitDmgBonus`                | Stonesplit channel multiplier                     |
| `silkbindDmgBonus`                  | Silkbind channel multiplier                       |
| `bamboocutDmgBonus`                 | Bamboocut channel multiplier                      |
| `physicalAttackBonus`               | Physical attack scaling                           |
| `bellstrikeAttackBonus`             | Bellstrike attack scaling                         |
| `stonesplitAttackBonus`             | Stonesplit attack scaling                         |
| `silkbindAttackBonus`               | Silkbind attack scaling                           |
| `bamboocutAttackBonus`              | Bamboocut attack scaling                          |
| `allMartialArts`                    | Category 1 (MartialArts)                          |
| `vsBossDmg`                         | Category 1 (boss)                                 |

Bonuses add within their category before its multiplier is formed. Base damage, Category 1, matching attunement, Mechanism, DOT, channel, and outcome stages are distinct. `attributeDMGBonus` joins Category 1 only for attribute components. `highBleedDamage` shares the DOT multiplier pool for HighBleed-tagged actions. Mechanism fields add together, with the Bellstrike-only field joining only that channel. `flatAttackBonus` scales authored flat attack terms, not the full hit. Replay bonuses apply after source final damage; they do not reapply ordinary hit multipliers.

## Datamine checklist

- Match the game buff/skill ID and normal versus preview variant. Repository IDs below are lookup keys, not numeric game IDs.
- Record the exported property and calculation cause/category, value units, target channel, requirements, rank, and stack behavior.
- Verify whether separate bonuses add or multiply, including PvE-only bonuses and conditional upgrades.
- Record the export version, evidence location, confirmed category, and any discrepancy before changing data.
