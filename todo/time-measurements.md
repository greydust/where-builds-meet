# Combat Time Measurements

The following placeholder timings need direct in-game measurement before they
should be treated as confirmed weapon-specific values.

## Deflect

Gauntlet Deflect is measured at `0.3s`. Measure Deflect duration for every
other weapon family; the simulator currently uses the previous shared value of
`0.338s` as their placeholder:

- Heng Blade
- Mo Blade
- Spear
- Umbrella
- Rope Dart
- Sword
- Fan
- Dual Blades
