# Combat Time Measurements

The following placeholder timings need direct in-game measurement before they
should be treated as confirmed weapon-specific values.

## Deflect

Measure Deflect duration for every weapon family. The simulator currently uses
the previous shared value of `0.338s` for all weapons:

- Heng Blade
- Mo Blade
- Spear
- Umbrella
- Rope Dart
- Gauntlet
- Sword
- Fan
- Dual Blades

every other weapon family; the simulator currently uses `0.5s` as their
placeholder:
